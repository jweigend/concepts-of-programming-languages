# Functional Programming

## Purpose

This directory contains examples demonstrating **functional programming concepts** in Go.

## Subdirectories

| Directory | Topic | Description |
|-----------|-------|-------------|
| `clojures/` | Closures | Functions capturing environment variables |
| `composition/` | Composition | Combining functions (g∘f) |
| `lambdacalculus/` | Lambda Calculus | Church numerals and pure functions |
| `parser/` | Parser Combinators | Functional parsing approach |
| `streams/` | Streams | Map/Filter/Reduce API |

## Key Concepts

- **First-class functions** - Functions as values
- **Higher-order functions** - Functions taking/returning functions
- **Immutability** - Avoiding side effects
- **Composition** - Building complex from simple
