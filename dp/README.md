# Design Patterns

## Purpose

This directory contains examples of common **design patterns** implemented in Go.

## Subdirectories

| Directory | Pattern | Description |
|-----------|---------|-------------|
| `idserv/` | Proxy/Stub | Remote service with network transparency |
| `kvstore/` | Proxy/Stub | Distributed key-value store |

## Key Concepts Demonstrated

- **Proxy Pattern** - Placeholder for remote object
- **Stub Pattern** - Server-side request handling
- **Interface-based Design** - Decoupling API from implementation
- **Network Transparency** - Same interface for local and remote
