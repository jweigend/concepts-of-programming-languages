# Hello World

## Purpose

The classic **"Hello World"** example in Go. This demonstrates basic string output and UTF-8 character handling.

## Key Concepts

- **`fmt.Printf()`** - Formatted output to stdout
- **UTF-8 support** - Go natively supports Unicode characters
- **Hex escape sequences** - `\xE2\x98\xAF` represents the Yin-Yang symbol (☯)

## Run

```bash
go run main.go
```

## Output

```
Hello Programming with Go ☯
Hello Programming with Go ☯
```

## Test

This example has no tests. It is a runnable demonstration.
