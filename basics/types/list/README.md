# List

## Purpose

This example demonstrates a **linked list implementation** in Go using pointers and recursive data structures.

## Key Concepts

- **Recursive struct definition** - Node pointing to next node
- **Pointer manipulation** - Building and traversing the list
- **nil handling** - End of list marker

## Run

```bash
go run lists.go
```

## Test

This example has no tests. It is a runnable demonstration.
