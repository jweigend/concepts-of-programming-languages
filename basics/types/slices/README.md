# Slices

## Purpose

This example demonstrates **slice operations** in Go, which are fundamental to Go programming.

## Key Concepts

- **Slice creation** - `make()`, literals, slicing arrays
- **Slice manipulation** - `append()`, copy, reslicing
- **Slice internals** - Length vs capacity, underlying arrays

## Run

```bash
go test -v
```
